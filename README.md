# KLHash - Windows 文件哈希计算工具

**KLHash** 是一款基于 C# 与 WinForms 开发的桌面端极简文件哈希值计算工具。支持批量文件处理、拖拽操作、实时进度显示与结果一键复制。

---

## 🖱️ 功能简介

* **快速交互体验**：
* **拖拽支持**：支持将一个或多个文件直接拖拽入界面进行批量计算。
* **文件选择**：提供原生多选文件对话框。
* **灵活便捷功能**：
* **大小写无缝切换**：支持随时切换 Hash结果的英文字母大小写。
* **随时取消中断**：支持在计算大文件或多文件过程中随时取消任务。
* **一键复制结果**：一键将格式化好的文件名与哈希值复制到系统剪贴板。

---

## 🖥️ 界面操作说明

1. **选择文件**：
   * 点击 **选择文件** 按钮选取文件（支持多选）。
   * 或直接将文件 **拖拽** 至应用程序界面。
2. **计算过程**：
   * 底部进度条将实时显示当前单个文件的计算进度。
   * 底部状态栏显示总进度与当前正在处理的文件名。
3. **查看与复制**：
   * 勾选/取消勾选 **大小写** 复选框可动态格式化结果。
   * 点击 **复制** 按钮即可将文本框中的结果复制到剪贴板。



---

## ⌨️ 环境算法

* **运行框架**：.NET 8+ WinForms
* **支持系统**：Windows 10+
* **支持算法**：SHA-256
